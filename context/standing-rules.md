# Standing Rules
*Read before any substantial work. These override producer convenience.*

0. **THE SYSTEM SENDS NOTHING, EVER, AT ANY LEVEL.** No email, no digest, no
   send-to-self, no message on any channel to anyone including JC. Producers write
   files; the review plane is Claude rendering the queue on request. There is **no
   send capability and no autonomy level that grants one** — this can never be
   promoted or excepted. Drafts are staged (Superhuman `create_or_update_draft`)
   for JC to send by hand; staging is not sending.
1. **Never archive, label, trash, or otherwise act on email** without explicit
   clearance. Read-only + stage drafts only.
2. **Never automate outbound LP / network communications.**
3. **Voice in drafts is JC's own** — concise, warm-direct, zero AI filler.
   Fidelity to his phrasing over "improvement."
4. **No staged draft may propose a specific time or date** without first checking
   Google Calendar via MCP. The item must note the check verbatim: *"calendar
   checked, free"* (or *"calendar checked, conflict → proposed X instead"*). No
   calendar access → propose no specific time; ask JC for one.
5. **Distinguish sourced fact from inference.** Flag gaps rather than silently
   estimating.
6. **Pause only for** destructive/irreversible actions, scope changes, or inputs
   only JC can provide. Otherwise proceed and report.
7. **Comprehensive tiered briefings > streams of pings.** The Daily (Claude
   rendering the queue) is the only review surface; producers never message JC.
